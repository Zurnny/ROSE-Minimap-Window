# Minimap Window

While the minimap is minimized, an empty see-through window sits under the zone name and time. Clicks go straight through it to the game.

Inside it is an **element chart**: each element (Wind, Earth, Fire, Water, Neutral, Poison, Sorcery, Ghost, Holy) with the icons of the elements it is strong against and weak against, taken from the game's own monster info.

Press the small gear on it for its settings:
- **Opacity**: 0% is fully clear, 100% is solid.
- **Show element chart** on or off.

Settings are saved in `sp_minimap_window.txt` in the game folder.

An add-on for [ROSE Mod Launcher](https://github.com/Zurnny/Rose_Mod_Launcher), for the game's **default** UI.

## Install
1. Download this repo (Code > Download ZIP) and open it.
2. Copy the **Minimap Window** folder into `Launcher Mods` in your ROSE Online folder.
3. Open the launcher, press **Mods**, tick **Minimap Window**, and restart the game.

It updates itself from this repo whenever the launcher opens.
